# Security Policy

## Supported version

Security fixes are applied to the latest revision of the default branch.

## Reporting a vulnerability

Report suspected vulnerabilities privately through the repository's GitHub
Security Advisory page. Include reproduction steps, affected configurations, and
the expected impact. Do not include credentials, private prompts, model weights,
or customer data in an issue, pull request, or public discussion.

Please allow time to validate and coordinate a fix before public disclosure.
